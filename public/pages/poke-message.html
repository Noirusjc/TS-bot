Poke Message Template

Customize the message sent to users when their temporary channel is created.

📌 Available Placeholders
{USER_NICKNAME} {CHANNEL_NAME} {CHANNEL_PASSWORD}

Supports TeamSpeak BBCode: [color=#FF0000]text[/color], [b]bold[/b], [i]italic[/i]

🔐 Template (Password Enabled)

Used when channel password is enabled.

—
🔓 Template (No Password)

Used when channel password is disabled.

—
ℹ️ Notes

• TeamSpeak poke messages are limited to ~100 characters per message. The bot sends each line as a separate poke.
• If a user's nickname contains special characters, they are automatically sanitized to prevent command injection.
• The default template uses TeamSpeak's BBCode color system for a professional appearance.
